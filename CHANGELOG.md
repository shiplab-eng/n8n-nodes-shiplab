# Changelog

All notable changes to `@shiplab-eng/n8n-nodes-shiplab` are documented here. This project follows
[semantic versioning](https://semver.org/).

## 0.1.2

Initial public release.

- **Shiplab Profile** — get and update the authenticated customer profile.
- **Shiplab Connector Group** — get many, get, create, update, delete.
- **Shiplab Connector** — get many, get, create, update, delete, with carrier-specific
  connection fields loaded from the API.
- **Shiplab Carrier** — get connection config.
- **Shiplab Invoice** — paginated search and unpaginated customer invoice retrieval.
- **Shiplab API** credential with configurable base URL.
